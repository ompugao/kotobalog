# ことばログ (KotobaLog) 📖

お子さまが話した「ことば」「意味・エピソード」「録音（声）」「話した日時」の4点を記録し、当時の月齢・年齢とともにタイムラインやカレンダーで振り返ることができる **Flutter (Web / Android 両対応) + Go バックエンド** の家族共有アプリケーションです。

複数のお子さまがいる場合でも、お子さまごとの **「ことば帳 (`notebooks`)」** を作成してワンタップで切り替え・家族共有ができます。

---

## 主な機能

- **お子さまごとの「ことば帳」切り替え (`notebooks`)**
  - お子さまの名前・生年月日・アイコン絵文字・テーマカラーを設定して複数の「ことば帳」を作成可能。
  - 上部バーから兄弟・姉妹のことば帳をワンタップで切り替え。
- **家族共有（招待コード）**
  - 8桁の招待コードを発行し、パパ・ママ・おじいちゃん・おばあちゃんなど家族みんなで同じ「ことば帳」に記録・閲覧が可能。
  - 誰が記録した言葉かも自動で表示されます。
- **ことば・意味・録音・日時の記録**
  - Webブラウザ / Androidアプリの双方でマイク録音（16-bit PCM → RIFF WAV変換）とワンタップ再生に対応（録音なしのテキストのみ記録も可）。
  - 記録した日時に応じて、お子さまの生年月日から **当時の月齢・年齢（例: `生後8ヶ月`, `1歳5ヶ月`）** を自動計算して表示。
- **振り返り機能**
  - **タイムライン & キーワード検索**: 話したことばや意味・エピソードでインクリメンタル検索。
  - **カレンダー表示**: 日別の記録状況をドットマーカーで可視化し、日付をタップしてその日のことばを振り返り。
- **認証**
  - メールアドレス＆パスワード認証に加え、環境変数設定により **Google OAuth2 / GitHub OAuth2** ログインに対応。

## 開発環境 (`mise`)

本リポジトリは [`mise`](https://mise.jdx.dev/) でツールバージョンとタスクを管理しています。

```bash
# ツールの有効化確認
mise trust
mise install

# バックエンドのテスト実行
mise run test-backend

# Flutterアプリの静的解析・テスト実行
mise run test-app

# Flutter Web のビルド (backend/web_dist に出力)
mise run build-web

# バックエンドサーバー起動 (http://localhost:8080)
mise run dev-backend
```

## 自前 NAS へのデプロイ (Docker Compose)

NAS上でコンテナ1つ（SQLite + ローカル音声ファイル保存 + Go API + Flutter Web配信）で完結します。

```bash
cp .env.example .env
# 必要に応じて .env 内の JWT_SECRET や GOOGLE_CLIENT_ID / GITHUB_CLIENT_ID 等を編集

docker compose up -d --build
```

- Webアプリ: `http://<NASのIPアドレス>:8080`
- Androidアプリから接続する場合: ログイン画面下部の「接続先サーバー (NAS)」に `http://<NASのIPアドレス>:8080` を設定してください（Androidエミュレータの場合はデフォルトで `http://10.0.2.2:8080` に接続します）。
- 永続化データ: `./data/kotobalog.db`（SQLite）および `./data/audio/`（音声ファイル）に保存されます。
